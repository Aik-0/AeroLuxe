AeroLuxe English Demo Website

Files:
- index.html: page structure and English content
- style.css: responsive dark luxury design
- app.js: sample flight data, route filtering, date validation, airline filter, and demo booking modal

How to run:
1. Keep all three code files in the same folder.
2. Open index.html in your browser, or use Live Server in VS Code.
3. The flight list and prices are sample/demo data only.
4. The confirmation dialog does NOT book a real flight and does NOT process payments.
5. Prices are shown in USD for this design demo. Connect a real flight inventory and secure booking/payment backend before using this as a real service.
